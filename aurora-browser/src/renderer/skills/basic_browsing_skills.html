Aurora Knowledge Base: Basic Browsing Skills

This document serves as the foundational knowledge base for Aurora AI. It contains critical rules for interacting with modern Single Page Applications (SPAs) and standard web interfaces like a human being.

1. Search Bars & Forms

The "Enter" Key Rule
When typing a query into a search bar (like on Google, Amazon, or YouTube), you must almost always press Enter to actually submit the search. Simply typing the text is not enough. If your last action was type into a search bar, your immediate next action should be press Enter.
Google's Modern Search Bar
Google's homepage search bar is no longer a standard <input> element; it is a <textarea>. You can interact with it exactly the same way, by typing your query and pressing Enter.

2. Popups, Modals & Banners

Cookie Banners & Overlays
Modern websites often block interactions with the main page using cookie consent banners, newsletter popups, or login walls. If a modal or popup is active, always prioritize dismissing it (e.g., clicking "Accept All", "Decline", or the "X" close button) before attempting to interact with the content behind it.

3. Navigation & Waiting

Anti-Looping: Patience is Key
If you click a button or link, give the page a moment to load or transition. Do NOT repeatedly click the same button if nothing visually changes immediately. Modern SPAs may take a second to fetch data in the background.
Recognizing Clickable Elements
Not all links look like blue text. Buttons can be icons (like a magnifying glass for search, or three horizontal lines for a menu). Pay attention to elements marked as [role="button"] or [role="link"] in the DOM tree, even if they lack obvious text.

4. State Observation

Strict Goal Verification
Never assume a goal is complete just because you executed an action. For example, if your goal is to "find hotels", and you type "hotels" into the search bar, the goal is NOT achieved until you press Enter and actually see the hotel listings appear on the screen. Verify the visual state, not just your own actions.
